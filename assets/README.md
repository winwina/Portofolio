# Assets

Letakkan aset statis di sini.

- `images/` — foto profil, ikon, ilustrasi
- `resume/` — file resume (PDF) untuk tombol "Download Resume"

Pada Fase 1 foto profil masih berupa placeholder di dalam hero section.
Untuk mengganti dengan foto asli, simpan gambar di `assets/images/` lalu
ganti elemen `.profile__placeholder` di `components/hero.js` dengan tag `<img>`.
